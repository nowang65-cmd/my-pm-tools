用你自己的 GitHub 帳號當雲端：資料會存成一個私人 Gist，所有裝置連到同一個 Gist 就能同步（以最後修改的為準）。
① GitHub → 右上頭像 → Settings → Developer settings → Personal access tokens → Tokens (classic) → Generate new token (classic)，只勾選 gist，複製 Token。
② 貼在下方按「儲存並同步」。第一台留空 Gist ID，系統會自動建立並顯示 ID。
③ 其他裝置貼上同一個 Token 與 Gist ID即可。
⚠ Token 會存在這台裝置的瀏覽器裡，請勿在公用電腦使用。
